# NeoSync 1.3.3-beta.7

Integrates upstream Neo 1.4.3 through 1.4.7.

- Faster paragraph word counts and fixes for cursor jumps when splitting or removing chapters and scene breaks.
- Duplicate books, including notes and covers. NeoSync waits for queued saves and prevents incoming sync or an update restart during copying.
- More capable outline cards: multiple selection/deletion, pasted lists, and chapters or scenes held on loose cards with their writing preserved.
- Paperback for KDP exports an interior PDF and matching cover-template PDF using bundled offline pagination and hyphenation. NeoSync keeps the book open and prevents an update restart during setup and export.
- More appearance preferences stay on each device, including shelf zoom. Export dialogs remember their last folder on that device.
- Screenplay title formatting, Swedish spellcheck, cleaner saved chapter formatting, and fixes for daily word counts after disk refreshes and the Linux read-aloud shortcut.

Update all devices before using loose cards that hold manuscript text. Older NeoSync versions do not understand the new card contents; moving or deleting those cards in an older app can discard their stored writing. Keep separate backups.

NeoSync identity, profile/library locations, Linux keyring selection, Nextcloud credentials, and the NeoSync-only update feed are preserved. Installed Windows builds and Linux x64 AppImages from beta.3 onward can download this version once it is published. Choose **Restart to update**; ordinary quitting does not install it.

Validation covers unit tests, typing/count accuracy, cursor behavior, tab navigation, queued saves and failures, duplication, actual paperback PDF generation, credential persistence, sync UI, and updater checksum rejection. Windows and Linux CI also verify installers, update metadata, packaged dictionaries, and the offline printing assets/licenses.

Paperback output still needs visual review with representative full-length manuscripts and validation in KDP's previewer; generating a PDF is not a guarantee that a particular book meets all publishing requirements. Full live two-device recovery, live KDE Wallet, Linux voice output, and installed-to-installed automatic upgrades remain manual test gaps. New upstream strings may fall back to English. Windows builds are unsigned.

The existing build-tool dependencies currently report npm audit advisories (8 moderate, 1 high). They are development dependencies; resolving them is separate from this upstream integration.
