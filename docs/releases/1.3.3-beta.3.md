# NeoSync 1.3.3-beta.3

Adds automatic update downloads from **Arianic/NeoSync releases** for installed Windows x64 builds and Linux x64 AppImages. The upstream Neo baseline remains 1.3.5.

## Updating

- Install this version manually once: earlier NeoSync versions have no enabled updater.
- After installation, NeoSync checks at startup, hourly while open, and after waking. Eligible updates download quietly. On the bookshelf, hover over the header to see **Update ready**, or use **Help → Check for Update…**.
- Choose **Restart to update** when ready. NeoSync waits for local saves and active sync work before restarting; a failed save leaves the app open. It does not install on an ordinary quit or interrupt writing.
- Only published NeoSync releases are considered. Drafts, original Neo tags, and older versions are excluded. Beta installations receive newer betas or stable releases; stable installations receive stable releases only.
- Windows portable executables and Linux Debian packages use a release-page download link. AppImages must run normally from a writable location; extracted builds require manual replacement. macOS and ARM64 self-updating are not supported.

## Validation and limits

Automated coverage checks release selection, beta/stable rules, source and metadata validation, real updater downloads using inert local test payloads, checksum failure, and restart save barriers. CI validates generated update metadata against the actual installer hashes on Windows and Linux.

A complete installation-to-installation upgrade still needs manual testing on both platforms. Windows builds remain unsigned. Downloads use HTTPS from the NeoSync repository and the updater verifies SHA-512 hashes; these hashes do not replace a publisher signature.

Nextcloud synchronization remains a beta: keep separate backups and use a disposable library for testing. Full live two-device conflict/recovery testing and live KDE Wallet testing remain incomplete. Existing NeoSync library and account paths are preserved.
