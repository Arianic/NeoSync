# NeoSync 1.3.3-beta.2

Integrates Neo 1.3.5 (`b742c5f92a5465fe8473e8d10aa05b3f0ea8a5a0`) while retaining NeoSync's Nextcloud integration and separate application identity. NeoSync uses its own release versions; its upstream baseline is recorded in `UPSTREAM.md`.

## Changes

- Outline index cards for chapters, sections and screenplay scenes, including loose ideas, card rearrangement and chapter-to-section conversion.
- Screenplay suggestion and layout improvements, keyboard navigation fixes, formatting-menu indicators, and updated translations from Neo.
- A NeoSync saving fix ensures an open outline-card note is committed before returning to the bookshelf, closing the window, or explicitly starting sync. Background saves do not close a card being edited.
- Nextcloud credentials, library locations, conflict recovery, and manual app updates retain NeoSync's existing behavior.

## Verification and limits

Regression coverage includes outline notes reaching disk before sync, new outline metadata transferring between devices, independent note edits merging, and competing notes being retained for review. The Windows and Linux CI checks cover saving/recovery, credentials, restart persistence, the desktop interface and installer builds.

This remains a beta. Full live two-device conflict/recovery testing is incomplete. Use a disposable library first and keep separate backups. Linux requires a working, unlocked GNOME Keyring/Secret Service or KDE Wallet; KDE Wallet is not live-tested. Windows builds are unsigned. macOS, ARM64 and mobile builds are not supported release targets.

Close NeoSync before installing an update, and use the same NeoSync version on both devices. Existing NeoSync profiles and libraries retain their paths. Updates are installed manually from this repository's releases.
