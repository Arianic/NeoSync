# NeoSync 1.3.3-beta.8

Integrates upstream Neo 1.5.7, including book snapshots, chapter notes, footnotes, manuscript-format Word/PDF export, page view and width choices, chapter import, improved structural undo/redo, Linux read-aloud fixes, and background backups. Adds Korean interface text and bundled fonts, updated Spanish text, and the optional simple interface (File → Show More Features). Nextcloud and update controls remain available in both modes.

## Sync and recovery

Snapshots sync between Windows and Linux. Each NeoSync snapshot stores every chapter so independently created device histories cannot borrow the wrong text from one another. This uses more space than upstream's incremental snapshots. Unchanged snapshots are still skipped; automatic snapshots retain upstream's 30-day retention. Snapshot manifests transfer after their chapter files, restores verify chapter fingerprints, and pruning records recoverable deletions first.

Chapter notes, outline notes, and footnotes travel with the library. Snapshot creation drains before closing the book; chapter import and snapshot restoration block book switching and update restart until complete. Manuscript export also holds the book open and waits for saves.

## Compatibility

Update all devices before using the new notes, footnotes, and snapshots. Earlier NeoSync versions do not understand all of these features and do not transfer snapshot folders. Avoid editing the same library with older versions or upstream Neo. Existing settings, library folders, Nextcloud credentials, updater feed, and Windows/Linux application identity are retained.

## Validation and limitations

Automated coverage includes sync reconciliation/recovery, incomplete and independent snapshots, chapter-note/footnote transfer, save barriers, native editor/export tests, and packaged runtime/font/license verification on Windows and Linux. Review the PR's final CI result before merging.

A live Nextcloud two-device exercise and installed-to-installed upgrade remain manual release checks. PDF generation does not replace visual review of a full manuscript or validation in a print provider's previewer. KDE Wallet and Linux speech still need manual testing on those systems. New strings without translations use English. Windows builds remain unsigned; macOS and mobile distributions are not supported by this fork. This integration does not update the existing development/build dependencies or their previously reported audit findings.
