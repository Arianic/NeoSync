# NeoSync 1.3.3-beta.6

Integrates upstream Neo 1.3.9 through 1.4.2, with additional integration work for Nextcloud sync and safe update restarts.

## Writing and recovery

- More reliable whole-file saves and recovery of library metadata and temporary files. An unavailable chosen library folder is no longer silently replaced.
- Chapter saves run in order and check for competing disk changes before writing. The competing text is preserved as a separate chapter.
- Failed notes, comments, and Darlings writes remain queued for retry. NeoSync waits for queued saves before returning to the bookshelf, allowing incoming sync, or restarting to update; a failed save prevents that handoff.
- Shelf exports pause incoming sync while reading the book. Restart waits until opening or exporting a book has finished.
- Upstream fixes improve preservation of words during moves, structural undo, paste, and import.

## Other upstream changes

- Word export improvements for fonts, styles, and regional paper size; better PDF typography and export from the bookshelf.
- Faster paragraph editing, tab keyboard navigation, and outline-card improvements.
- Screenplay page breaks and per-script heading/returning-speaker preferences.
- Hungarian interface, spellcheck, and cover lettering, plus translation fixes. The Hungarian dictionary includes its source data and license notices.

## Updating and validation

Nextcloud connections, the Linux keyring fix, application identity, and the NeoSync-only update feed are retained. Once published, this release can be downloaded by installed Windows builds and Linux x64 AppImages from beta.3 onward. Choose **Restart to update**; ordinary quitting does not install an update. Other installation types still need a manual update.

Automated checks cover sync conflicts and recovery, real queued chapter/notes/comment saves, delayed and failed writes, restart and incoming-sync barriers, shelf-export coordination, tab shortcuts, credential persistence, Linux keyrings, updater checksums, and packaged dictionaries/licenses. Full live two-device recovery, live KDE Wallet, Linux voice output, and a complete installed-version automatic upgrade still require manual testing. Windows builds remain unsigned; keep separate backups while using the beta.
