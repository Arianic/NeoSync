# NeoSync 1.3.3-beta.5

Integrates upstream Neo 1.3.6 through 1.3.8 while retaining NeoSync's Nextcloud sync, Linux keyring selection, and automatic updates from this repository.

## Upstream improvements

- Windows saves wait briefly when another program temporarily holds a file open. Persistent failures still keep the original chapter and report the problem.
- Books reopen on their last tab, with the manuscript's position preserved separately.
- Novel, screenplay, and outline-card zoom are remembered separately on each device instead of being written into the shared library.
- PDF section breaks regain their spacing. EPUB exports include language information, justified body text, and hyphenation.
- German single quotation marks and dashes, spellcheck/help shortcuts, and translations receive fixes.
- Linux read aloud enables Speech Dispatcher and offers Ctrl+Shift+K. A working Speech Dispatcher service and voice are required.
- AppImage packaging adopts upstream's newer runtime to avoid the older libfuse2 requirement.

## Updating and validation

The library, saved accounts, recovery copies, and NeoSync update source retain their existing locations and formats. Windows installed builds and Linux x64 AppImages from beta.3 onward can download this version after it is published; choose **Restart to update**. Older versions, portable Windows builds, Debian packages, and extracted AppImages require manual updates.

Verification covers unit tests, native desktop saves and restart barriers, device-local zoom, last-tab restoration, sync UI, Linux keyring selection, updater downloads, and packaging metadata. Full live two-device conflict/recovery testing, live KDE Wallet testing, Linux voice output, and a complete installed-version automatic upgrade still require manual testing. Windows builds remain unsigned. Keep separate backups while using the beta.
