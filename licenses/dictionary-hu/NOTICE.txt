Source availability

The dictionary source files index.aff and index.dic are included verbatim
with every packaged app, together with the upstream license, in the same
directory as this notice:
  app.asar.unpacked/node_modules/dictionary-hu/

The same files are available from the pinned source package:
https://registry.npmjs.org/dictionary-hu/-/dictionary-hu-3.0.0.tgz
Package project: https://github.com/wooorm/dictionaries/tree/main/dictionaries/hu
Dictionary project: https://github.com/laszlonemeth/magyarispell

Hunspell reads index.aff and index.dic exactly as distributed; no
conversion is applied.
